# 🏢 FloorPlan Studio

### Интерактивные поэтажные планы здания с особыми объектами

Красивый, быстрый и отзывчивый веб-просмотрщик плана этажа. Плавный зум, продуманная до
мелочей векторная отрисовка и умные подсказки при выборе объекта — лифта, камеры или банкомата.

## ✨ Возможности

- 🎨 **Премиальная отрисовка плана** — киллер-фича. Векторный SVG-план в стиле
  *Modern Minimal*: слоистый рендер, мягкие тени, пастельные градиенты, аккуратная
  типографика. Идеальная чёткость на любом масштабе.
- 🔍 **Плавный зум и панорамирование** — колесо мыши, перетаскивание, кнопки управления.
  Плавная инерция, ограничение границ, сброс одним кликом.
- 📍 **Особые объекты** — лифты 🛗, камеры 📷 (с конусом обзора!), банкоматы 💳.
  Наведение и выбор с анимированной подсветкой.
- 💬 **Умный поповер** — при клике по объекту всплывает карточка с детальными данными:
  статус, характеристики, дата обслуживания и т.д. Позиционируется с защитой от выхода
  за края экрана.
- 🏗️ **Несколько этажей** — переключение между этажами здания.
- 🎛️ **Фильтры и легенда** — показ/скрытие объектов по типам, понятная расшифровка цветов.
- ⚡ **Реактивное состояние на MobX** — точечные перерисовки, отзывчивый UI.

## 🧱 Технологии

| Слой | Технология | Зачем |
|---|---|---|
| Сборка | **Vite 8** | Молниеносный dev-сервер, современная сборка |
| UI | **React 19 + JavaScript (JSX)** | Декларативный UI, чистый JS (без TypeScript) |
| Визуализация | **SVG (hand-built)** | Векторная графика, нативные клики, чёткость на любом зуме |
| Зум/пан | **react-zoom-pan-pinch 4** | Готовое плавное масштабирование с инерцией |
| Поповер | **@floating-ui/react 0.27** | Умное позиционирование поповера |
| Иконки | **lucide-react** | Аккуратные иконки интерфейса |
| Состояние | **MobX 6 + mobx-react-lite** | Реактивные сторы, точечные перерисовки |
| Стили | **CSS Modules + CSS-переменные** | Изоляция + единая дизайн-система |
| Качество | **ESLint + Prettier** | Единый стиль кода |

## 🚀 Быстрый старт

### Требования
- **Node.js ≥ 20** (рекомендуется LTS)
- **npm ≥ 10**

### Установка и запуск

```bash
# 1. Установить зависимости
npm install

# 2. Запустить dev-сервер
npm run dev
```

Откройте адрес из вывода в консоли (по умолчанию `http://localhost:5173`).

### Остальные команды

```bash
npm run build     # продакшн-сборка в dist/
npm run preview   # локальный превью продакшн-сборки
npm run lint      # проверка линтером
npm run format    # форматирование кода
```

## 🖼️ Визуальная концепция

Стиль **Modern Minimal** — светлый, воздушный, премиальный, в духе современных продуктовых
UI (Apple/Linear):

```
┌─────────────────────────────────────────────────┐
│  ┌────────────┐  ┌───────┐  ┌────────────┐       │
│  │   ХОЛЛ     │  │ КАФЕ  │  │    ОФИС    │       │  пастельные
│  │            │  │       │  │            │       │  градиенты
│  │     🛗     │  │  📷   │  │            │       │  мягкие тени
│  └────────────┘  └───────┘  └────────────┘       │  тонкие линии
│                       💳                          │
│  ┌──────────┐                       ┌──────────┐  │
│  │ ПЕРЕГОВ. │  · · · коридор · · ·  │  СЕРВЕР  │  │
│  └──────────┘                       └──────────┘  │
└─────────────────────────────────────────────────┘
  свет · воздух · премиум
```

Слои рендера (снизу вверх): фон-сетка → пол здания → комнаты → стены → двери → подписи →
объекты → эффекты (свечение/тени). Каждый слой отвечает за свою часть «дорогой» картинки.

## 📂 Структура проекта

```
bank-stages/
├─ src/
│  ├─ main.jsx               # точка входа + провайдер MobX
│  ├─ App.jsx                # корневой layout
│  ├─ index.css              # глобальная тема (CSS-переменные)
│  ├─ data/building.js       # мок-данные (этажи, комнаты, объекты)
│  ├─ state/                 # MobX-сторы (классы)
│  ├─ components/
│  │  ├─ FloorPlan/          # слоистый SVG-рендер (киллер-фича)
│  │  ├─ Controls/           # зум, этажи, фильтры
│  │  ├─ ObjectPopover.jsx   # поповер
│  │  └─ Legend.jsx
│  └─ utils/                 # чистые функции (геометрия)
├─ docs/                     # пользовательская документация
├─ specs/                    # технические спецификации модулей
├─ AGENTS.md                 # инструкция для ИИ-агентов
├─ technical.md              # зафиксированные технические решения
├─ context.md                # контекст и ограничения проекта
└─ plan.md                   # детальный план разработки
```
