# Спецификация: Особые объекты на плане

> Как рендерятся и ведут себя особые объекты (лифты, камеры, банкоматы). Компонент
> `src/components/FloorPlan/PlanObject.jsx`, иконки — `icons.js`. Цвета/токены —
> `design-system.md`, модель данных — `data-model.md`.

## 1. Общий принцип

Каждый объект — `<g transform="translate(x, y)" class="plan-object">`, позиционируется по
центру. Внутри группы — тип-специфичная графика. Поведение:
- **rest** — статичное состояние.
- **hover** — масштаб `scale(1.1)`, усиление свечения (`filter-object-glow`).
- **selected** — пульсирующая обводка-кольцо + свечение.

Видимость объекта зависит от `ui.visibleTypes.has(obj.type)` (фильтр).

## 2. Камера (`camera`) — с конусом обзора

Самый «функциональный» объект: показывает направление и угол обзора.

```
         направление (direction, 0°=вверх)
              ↑
          ╱─────╲   ← конус обзора (сектор)
        ╱         ╲     полупрозрачный, светящийся,
       ╱           ╲    радиальный градиент grad-camera-cone
      ╱     📷     ╲  ← иконка камеры в центре (violet)
       ╲           ╱
        ╲         ╱
          ╲─────╱
```

**Геометрия конуса:**
- Радиус конуса: фиксированный (например, `R = 120` единиц SVG), можно вынести в токен.
- Угол обзора: `obj.details.angle` (градусы, напр. 110°).
- Направление: `obj.details.direction` (градусы; 0 = вверх, по часовой).
- Сектор строится как `<path>` (дуга) или `<polygon>` из набора точек по углам.

**Стиль конуса:**
- `fill="url(#grad-camera-cone)"` — центр у камеры ярче (`--color-obj-camera`, opacity ~0.35),
  к краю → прозрачный.
- Лёгкая обводка края конуса: `stroke="--color-obj-camera"` `opacity ~0.3`, тонкая.
- `pointer-events: none` на конусе (клики идут по иконке/группе), чтобы конус не «перехватывал»
  клики по другим объектам/комнатам.

**Иконка камеры:** круг-капсула (`--color-obj-camera`) с белой иконкой объектива (из
`icons.js`). Блик + мягкая тень.

## 3. Лифт (`elevator`)

- Квадрат/капсула со скруглёнными углами, заливка `--color-obj-elevator` (blue), белая
  иконка кабины/стрелок внутри.
- Блик сверху + мягкая тень.
- Без конуса (не нужен).

## 4. Банкомат (`atm`)

- Бейдж (скруглённый прямоугольник или круг), заливка `--color-obj-atm` (emerald), белая
  иконка карточки/купюры.
- Блик + мягкая тень.

## 5. Состояния и анимации

### hover
- Группа: `transform: scale(1.1)` (transition `--duration-fast --ease-out`).
- Свечение: `filter-object-glow` (можно усилить `stdDeviation`).
- Курсор `pointer`.

### selected
- Поверх объекта — пульсирующее кольцо (`<circle>` с `@keyframes pulse`):
  - `r` пульсирует (напр. `18 → 26`), `opacity` (`0.6 → 0`).
  - Бесконечная анимация, ~1.6s, `--ease-out`.
- Сам объект — усиленное свечение + лёгкое увеличение.
- Цвет кольца — цвет типа объекта.

### rest
- Базовый масштаб `1.0`, тень/блик без свечения.

## 6. Интерактивность

- `onClick` → `selection.select(obj.id)`.
- `onMouseEnter`/`onMouseLeave` → локальный hover (можно `useState`, т.к. локально; либо
  через CSS `:hover` — предпочтительно, без JS).
- `cursor: pointer`, `role="button"`, `aria-label={obj.name}` (базовая a11y).
- Кликабельная область — вся группа (или увеличенная невидимая `<circle>` для удобного клика).

## 7. Унификация

- Все иконки объектов — **один визуальный вес и размер** (диаметр ~24–28 единиц SVG),
  независимо от типа. Различие — цвет + форма/иконка.
- Единый стиль блика/тени для всех типов (консистентность).

## 8. Чек-лист

- [ ] У камеры — видимый конус обзора (по `angle` + `direction`).
- [ ] Конус не перехватывает клики (`pointer-events: none`).
- [ ] Все три типа — единый размер/вес, цвет по типу.
- [ ] hover: scale + свечение, плавно.
- [ ] selected: пульсирующее кольцо + свечение.
- [ ] `onClick` вызывает `selection.select(obj.id)`.
- [ ] a11y: `role`, `aria-label`, `cursor: pointer`.
