# Спецификация: Дизайн-система (Modern Minimal)

> Единый источник правды по визуальному языку: палитра, типографика, тени, скругления,
> тайминги анимаций. **Инвариант** (см. `context.md` §5, `AGENTS.md` §3.2): значения не
> меняются без согласования. Цвета реализованы как CSS-переменные в `src/index.css`.

## 1. Философия стиля

**Modern Minimal** — светлый, воздушный, премиальный. В духе современных продуктовых UI
(Apple/Linear/Stripe). Принципы:

- **Воздух:** щедрые отступы, отсутствие визуального шума.
- **Глубина через мягкие тени,** а не тяжёлые обводки.
- **Пастельные, приглушённые** цвета; один акцент.
- **Тонкие, но читаемые** линии.
- **Аккуратная типографика** с чёткой иерархией.

## 5. Типографика

- **Семейство:** системный стек (без загрузки веб-шрифтов ради скорости):
  `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif`.
- **Scale:**
  | Токен | Размер | Вес | Назначение |
  |---|---|---|---|
  | `--font-display` | 20px | 700 | заголовок приложения |
  | `--font-title` | 16px | 600 | названия секций, шапка поповера |
  | `--font-body` | 14px | 400 | основной текст |
  | `--font-label` | 12px | 500 | подписи, бейджи |
  | `--font-caption` | 11px | 400 | мелкие детали, хинты |
- **Подписи комнат на плане** (SVG `<text>`): 12px, вес 600, цвет `--color-text-muted`,
  с подложкой-плашкой (`fill` полупрозрачный белый, радиус `--radius-sm`).

## 6. Анимации (тайминги и кривые)

Все переходы плавные, единообразные. Без рывков.

| Токен | Значение | Назначение |
|---|---|---|
| `--ease-out` | `cubic-bezier(0.22, 1, 0.36, 1)` | стандартный ease-out (большинство UI) |
| `--ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | лёгкий «спринговый» отскок (поповер, selection) |
| `--duration-fast` | `150ms` | hover микро-состояний |
| `--duration-base` | `220ms` | стандартные переходы |
| `--duration-slow` | `320ms` | появление поповера, крупные переходы |

- Hover объектов: scale `1.0 → 1.1`, усиление свечения, `--duration-fast --ease-out`.
- Selection: пульсирующее кольцо через `@keyframes pulse` (бесконечная, ~1.6s, `--ease-out`).
- Поповер: opacity `0→1` + translateY `8px → 0`, `--duration-slow --ease-spring`.

## 7. Отступы и расстояния

## 9. Токены для SVG-фильтров (имена `id`)

| id | Тип | Назначение |
|---|---|---|
| `filter-floor-shadow` | `feDropShadow` | мягкая тень под контуром этажа |
| `filter-room-shadow` | `feDropShadow` | лёгкая тень комнат |
| `filter-object-glow` | `feGaussianBlur` + `feMerge` | свечение объектов (hover/selected) |
| `grad-room-<type>` | `linearGradient` | заливка комнаты по типу |
| `grad-floor` | `radialGradient` | заливка пола этажа |
| `grad-camera-cone` | `radialGradient` | конус обзора камеры |

> Все фильтры/градиенты объявляются **один раз** в `<defs>` корневого SVG (ADR-006) и
> переиспользуются по `id`.
