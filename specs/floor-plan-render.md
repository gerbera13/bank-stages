# Спецификация: Рендер плана этажа (киллер-фича)

> Детальное описание слоистого SVG-рендера плана. Это спецификация **визуального движка**.
> Любая реализация обязана следовать порядку слоёв, фильтрам и эстетике. Источник правды для
> красоты. См. также `design-system.md`.

## 1. Принцип слоистого рендера

План — это упорядоченный набор SVG-слоёв (`<g>`), каждый со своей ролью. Порядок (снизу вверх)
фиксирован:

```
<g id="layer-background">   фон + сетка
<g id="layer-floor">        контур/заливка этажа (с тенью)
<g id="layer-rooms">        комнаты (заливка-градиент + обводка стен)
<g id="layer-doors">        двери (разрывы/дуги) — условно
<g id="layer-labels">       подписи комнат (плашки + текст)
<g id="layer-objects">      особые объекты (см. specs/objects.md)
<g id="layer-effects">      оверлеи/свечения при выборе (опционально)
```

> Объекты рендерятся **поверх** комнат/подписей, чтобы всегда быть кликабельными и видимыми.

## 2. `<defs>` — фильтры и градиенты (объявляются ОДИН раз)

Согласно ADR-006, все фильтры и градиенты объявляются в едином `<defs>` корневого `<svg>` и
переиспользуются по `id`. **Запрещено** объявлять фильтры инлайн на каждом элементе.

### Фильтры

Тень двухуровневая: короткая контактная задаёт толщину, длинная мягкая — высоту
над подложкой. Актуальные значения — в `src/components/FloorPlan/Defs.jsx`.

```html
<!-- Плита этажа парит над фоном -->
<filter id="filter-floor-shadow" x="-20%" y="-20%" width="140%" height="150%">
  <feDropShadow dx="0" dy="10" stdDeviation="10" flood-color="#0f172a" flood-opacity="0.28"/>
  <feDropShadow dx="0" dy="34" stdDeviation="34" flood-color="#0f172a" flood-opacity="0.42"/>
</filter>

<!-- Комнаты примыкают вплотную: тень короткая, иначе план мутнеет -->
<filter id="filter-room-shadow" x="-20%" y="-20%" width="140%" height="150%">
  <feDropShadow dx="0" dy="3" stdDeviation="2" flood-color="#0f172a" flood-opacity="0.22"/>
  <feDropShadow dx="0" dy="9" stdDeviation="8" flood-color="#0f172a" flood-opacity="0.3"/>
</filter>

<!-- Главный источник объёма: стены «выдавлены» над полом -->
<filter id="filter-wall-shadow" x="-25%" y="-25%" width="150%" height="160%">
  <feDropShadow dx="0" dy="3" stdDeviation="2" flood-color="#0f172a" flood-opacity="0.5"/>
  <feDropShadow dx="0" dy="10" stdDeviation="10" flood-color="#0f172a" flood-opacity="0.42"/>
</filter>

<filter id="filter-object-glow" x="-50%" y="-50%" width="200%" height="200%">
  <feGaussianBlur stdDeviation="3" result="blur"/>
  <feMerge>
    <feMergeNode in="blur"/>
    <feMergeNode in="SourceGraphic"/>
  </feMerge>
</filter>
```

`filter-wall-shadow` вешается на слои `layer-inner-walls` и `layer-outer-walls`
целиком (в `raw`-режиме — не вешается: там плоский исходный чертёж).

### Градиенты
- `grad-floor` — `<radialGradient>`: центр светлее, края чуть темнее («воздух»).
- `grad-room-<type>` — `<linearGradient>` (сверху светлее, снизу цвет типа комнаты) для
  каждого `RoomType` из `design-system.md`.
- `grad-camera-cone` — `<radialGradient>`: центр (у камеры) ярче/непрозрачнее, край конуса
  прозрачный.

## 3. Слой фона и сетки

- Лёгкая сетка через `<pattern id="pattern-grid" width="40" height="40">`: тонкие линии
  `stroke="#e2e8f0"` с `opacity ~0.4`, либо точки (`<circle r="1">`). Очень деликатно — не
  отвлекает, лишь даёт ощущение масштаба.
- `<rect width="100%" height="100%" fill="url(#pattern-grid)">` в `layer-background`.

## 4. Слой этажа (`layer-floor`)

- Внешний контур здания: `<rect>` или `<polygon>` по границам этажа.
- `fill="url(#grad-floor)"`, `filter="url(#filter-floor-shadow)"`.
- Радиус скругления углов внешний (например, `rx="16"`), чтобы выглядело «премиально».

## 5. Слой комнат (`layer-rooms`)

Для каждой комнаты — компонент `Room.jsx`:

```html
<g class="room">
  <polygon points="..." fill="url(#grad-room-hall)"
           stroke="var(--color-wall)" stroke-width="5"
           stroke-linejoin="round" filter="url(#filter-room-shadow)"/>
</g>
```

- `fill` — градиент по `room.type`.
- `stroke` — `--color-wall` (внешние) / `--color-wall-inner` (внутренние), толщина из
  дизайн-системы.
- `stroke-linejoin="round"` — скруглённые углы (мягкий вид).
- Тени комнат через `filter-room-shadow` (очень лёгкие, чтобы не «утяжелять»).

> На MVP разделение внешних/внутренних стен можно упростить: единая обводка `--color-wall`
> толщиной `--wall-thickness`. Уточнить в ходе Этапа 3.

## 6. Слой дверей (`layer-doors`)

Идёт **после** `layer-inner-walls`: створка и крестик рисуются в толще стены,
и слоем ниже их закрашивала бы перегородка.

- `style: 'cross'` (конвертер, make-stage.md §8.2) — створка `--color-door-leaf`
  ровно в толщину перегородки (не выпирает за её грани) плюс тонкая линия
  поперёк стены. Створка темнее стены, иначе не читается.
- Иначе — дуга открывания («классика») с белым разрывом в обводке.
- `style: 'sliding'` — раздвижная (выход на балкон): проём во всю толщину стены
  и два полотна внахлёст по разные стороны от её оси. Рисуется в `layer-windows`,
  после внешнего контура, иначе несущая стена закрашивает и проём, и полотна.
- Двери на периметре дополнительно прорезают внешнюю стену (`OuterDoorCut`
  в `layer-windows`, после `layer-outer-walls`).

### Объём элементов интерьера

Плоский полигон читается наклейкой на полу. Объёмные элементы собираются из трёх
слоёв: тень на полу → притенённая боковина (тот же контур, сдвинутый вниз на
`depth`) → верхняя грань с бликом (`grad-counter-top`).

- `counterCurve` — стойка: `feat.color` задаёт тон, `feat.depth` (по умолчанию 6)
  — высоту корпуса.
- `pouf` — мягкое круглое сиденье: тень + заливка `feat.color` + светлая макушка.

## 7. Слой подписей (`layer-labels`)

Для каждой комнаты — подпись:

```html
<g class="room-label">
  <rect x="..." y="..." width="..." height="..." rx="6"
        fill="#ffffff" fill-opacity="0.7"/>
  <text x="..." y="..." text-anchor="middle" dominant-baseline="middle"
        class="room-label-text">Главный холл</text>
</g>
```

- Позиция — `room.labelAnchor` или `polygonCentroid(room.polygon)`.
- Подложка-плашка (`<rect>`): полупрозрачный белый, чтобы текст не сливался с градиентом.
- Текст: `text-anchor="middle"`, `dominant-baseline="middle"`, шрифт `--font-label`
  (12px/600), цвет `--color-text-muted`.
- Длинные названия — обрезать или переносить (на MVP можно ellipsis/мелкий шрифт).

## 8. Слой объектов (`layer-objects`)

См. отдельную спецификацию `objects.md`. Объекты рендерятся поверх всех комнат/подписей.

## 9. Координаты и `viewBox`

- Корневой `<svg viewBox="0 0 1000 640">` (или по `floor.bounds`).
- Все координаты в данных — в этой системе.
- `preserveAspectRatio="xMidYMid meet"` — план центрируется, сохраняя пропорции.
- Зум/пан применяется к контейнеру (`react-zoom-pan-pinch`), не к `viewBox` (ADR-004).

## 10. Производительность (чек-лист)

- [ ] Фильтры/градиенты — единственный `<defs>`, переиспользование по `id`.
- [ ] Нет инлайн-фильтров на каждом элементе.
- [ ] Подписи комнат — без тяжёлых эффектов.
- [ ] Число узлов разумно (десятки комнат, десятки объектов).
- [ ] `transform` для зума — на контейнере, геометрия не пересчитывается.

## 11. Чек-лист «красиво» (визуальный QA)

- [ ] Комнаты не плоские — градиенты дают глубину.
- [ ] Тени мягкие, согласованное направление (свет сверху).
- [ ] Стены читаются как стены (толстые, аккуратные, скруглённые углы).
- [ ] Подписи читаемы, не сливаются с фоном.
- [ ] Примыкания комнат без зазоров/артефактов.
- [ ] Объекты — верхним слоем, всегда видимы и кликабельны.
- [ ] Общее ощущение — премиальный Modern Minimal (св. `design-system.md` §8).
