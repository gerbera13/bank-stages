# Документация FloorPlan Studio

Добро пожаловать в документацию проекта. Здесь — пользовательская и эксплуатационная
документация. Технические спецификации модулей живут в соседней папке [`../specs/`](../specs).

## Содержание

| Документ | Описание |
|---|---|
| [getting-started.md](./getting-started.md) | Установка, запуск, команды |
| [architecture.md](./architecture.md) | Обзор архитектуры и потоков данных |
| [usage.md](./usage.md) | Как пользоваться приложением (для конечного пользователя) |
| [contributing.md](./contributing.md) | Правила разработки и контрибьюшена |

## Для кого эти документы

- **getting-started / usage** — для любого, кто хочет запустить или пользоваться
  приложением.
- **architecture / contributing** — для разработчиков, которые дорабатывают проект.

## Связанные документы (в корне репозитория)

- [`../README.md`](../README.md) — обзор проекта.
- [`../technical.md`](../technical.md) — технические решения (ADR).
- [`../context.md`](../context.md) — контекст, ограничения, инварианты.
- [`../plan.md`](../plan.md) — детальный план разработки (для ИИ-агента).
- [`../AGENTS.md`](../AGENTS.md) — инструкция для ИИ-агентов.
- [`../specs/`](../specs) — технические спецификации модулей и дизайн-система.
