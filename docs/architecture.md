# Архитектура

Краткий обзор архитектуры приложения. Глубокие технические детали — в
[`../technical.md`](../technical.md) (ADR) и [`../specs/`](../specs).

## Обзор

Одностраничное приложение (SPA) на React. Состояние — MobX. Визуализация плана — нативный
SVG. Сборка — Vite.

## Поток данных

1. **Данные:** мок `src/data/building.js` импортируется в `RootStore.building`.
2. **Активный этаж:** `UiStore.activeFloorId` → computed `activeFloor` → `FloorPlan`
   рендерит его комнаты и объекты.
3. **Выбор объекта:** клик по `PlanObject` → `selection.select(id)` → `selectedObject`
   (computed) → `ObjectPopover` показывает детали, объект подсвечивается.
4. **Фильтры:** `TypeFilter` → `ui.toggleType` → `ui.visibleTypes` → `PlanObject` решает
   рендериться ли.
5. **Смена этажа:** `FloorSwitcher` → `ui.setActiveFloor` → сбрасывает выбор + меняет план.

## Ключевые принципы

- **Единый источник истины** — MobX-сторы. UI-компоненты — «глупые» отображалки + делегаты
  действий в стор.
- **Точечная реактивность** — `observer`-компоненты перерисовываются только при изменении
  читаемых ими observable-полей.
- **Чистые утилиты** — `src/utils/` без зависимостей от React/MobX (тестируемые).
- **Изоляция данных** — замена мока на бэкенд сводится к замене источника в `RootStore`.

## Слои рендера плана (киллер-фича)

План — упорядоченные SVG-слои (снизу вверх): фон/сетка → пол этажа → комнаты → двери →
подписи → объекты → эффекты. Все фильтры/градиенты — в едином `<defs>`. Детали — в
[`../specs/floor-plan-render.md`](../specs/floor-plan-render.md).

## Расширяемость

Архитектура закладывает точки расширения (без преждевременной реализации): новые типы
объектов, новые этажи, замена данных на бэкенд. См. ADR-009 в [`../technical.md`](../technical.md)
и Roadmap в [`../README.md`](../README.md).
