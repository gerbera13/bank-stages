### Pencil / pen.dev — как использовать
- Файлы: `~/.pencil/documents/<id>/*.pen` — читать/писать ТОЛЬКО через MCP pencil_*
- Старт: `pencil_get_app_state` с include_schema + include_canvas_design
- Рисование: `pencil_execute` (batch_design / Get / и т.д. по schema)
- Скрин: `pencil_get_screenshot`
- Экспорт: `pencil_export_nodes` — **только active document** (проверить session)
- Не использовать Read/Grep/Edit на .pen файлах

### pen.dev — честная оценка
Подходит: быстрый визуальный референс, детальная перерисовка «глазами», итерации с пользователем.
Слабо: точный CAD; стабильный export в код приложения; воспроизводимый pipeline.
Вывод: pen.dev = вспомогательный design-tool, НЕ замена Конвертера/SVG-рендера.

## Инструменты рисования: pen.dev и альтернативы

### Pencil / pen.dev (используем)
- **Что:** AI design canvas («Design on canvas. Land in code»), в OpenCode — MCP `pencil_*`.
- **У нас:** `~/.pencil/documents/<id>/*.pen`, сессия в `session-desktop.json`.
- **Плюсы:** уже интегрирован; удобно рисовать референс плана; batch_design; скриншоты узлов.
- **Минусы:** .pen только через MCP; export только **active** document; не является production-рендером app; координаты в React всё равно переносить руками/скриптом.
- **Вердикт:** хороший **вспомогательный** инструмент для визуальной перерисовки, не лучший **финальный** путь для продукта.

### Что лучше для наших целей

| Место | Инструмент | Вердикт |
|---|---|---|
| **#1 итог в продукте** | **Конвертер + FloorPlanSvg + building.js/blueprint** | Лучший: тот же стиль, что у живых этажей |
| **#2 визуальный референс** | **Pencil / pen.dev** (MCP) | Лучший среди canvas-AI здесь: уже есть в среде |
| **#3 дизайн-команда** | **Figma** (AI / Make / Dev Mode) | Сильнее pen как общий design-tool, но нет MCP в этой среде |
| Не для агента→app | Planner 5D, RoomSketcher, magicplan | Удобны людям, слабый путь в наш SVG/MobX |
| Не для стиля app | QCAD, LibreCAD, FreeCAD | Точный CAD, не Modern Minimal UI |
| Не архитектура | Excalidraw, tldraw | Схемы, не поэтажный стиль проекта |

**Итог:** рисовать референс можно в **pen.dev (Pencil MCP)**; сдавать результат нужно через **данные + FloorPlanSvg** (конвертер или `building.js`). Figma лучше pen как универсальный дизайн-редактор, но для этого репо pen.dev удобнее из‑за MCP. Planner 5D и CAD — не основной путь.
